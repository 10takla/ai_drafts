# Компиляция кастомизаций

Исходные поля определены в [формате черновиков](<../Формат черновиков.md>).

Имя пака (`<pack-name>`) соответствует `manifest.name`.

Итоговый `description` зависит от целевого формата:

```text
description(<manager>) = join(" ", [
  meta.description?,
  manifest.custom_conditions[<custom_condition>]*,
  "globs: <паттерны>."?
])
```

Фрагменты `manifest.custom_conditions`, выбранные через `<custom_condition>` в `meta.conditions`, включаются в `description` в порядке их перечисления.

## Преобразование черновиков

### Antigravity

- `manifest.yaml` → `plugin.json`.
- skill: `skills/<draft-name>/SKILL.md` с `name: <pack-name>:<draft-name>`.
- rule: `rules/<pack-name>-<draft-name>.md`.
- Вариант активации (`globs | description`):
  - `globs`: независимо от режима вызова → rule с `trigger: "glob"` и нативным `globs: <паттерны>` без `description`
  - `description` (только без `globs`):
    - `explicit_invocation` → skill с `description: ""` (даже при наличии `description` в черновике)
    - `implicit_invocation` → rule с `trigger: "model_decision"`.

### Codex

- `manifest.yaml` → `.codex-plugin/plugin.json`.
- skill: `skills/<draft-name>/SKILL.md`.
- `explicit_invocation` → skill с `policy.allow_implicit_invocation: false` в `skills/<draft-name>/agents/openai.yaml` и сохранением итогового `description` как есть (если он указан);
- `implicit_invocation` → skill по умолчанию.
- `globs` → `globs: <паттерны>.` в `description`.

### Claude Code

- `manifest.yaml` → `.claude-plugin/plugin.json`.
- skill: `skills/<draft-name>/SKILL.md`.
- `explicit_invocation` → `disable-model-invocation: true`.
- `implicit_invocation` → `user-invocable: false`.
- `globs` → `globs: <паттерны>.` в `description`.

### OpenCode

- `manifest.yaml` → без выходного файла.
- command: `commands/<pack-name>-<draft-name>.md`.
- skill: `skills/<pack-name>-<draft-name>/SKILL.md`.
- `explicit_invocation` → command.
- `implicit_invocation` → skill.
- `globs` → `globs: <паттерны>.` в `description`.

## Перенос сопутствующих ресурсов

Все дополнительные файлы и директории из папки черновика (кроме `meta.yaml` и `content.md`) рекурсивно копируются в целевую директорию скилла каждого менеджера агентов (`skills/<draft-name>/` для Antigravity, Codex, Claude Code и `skills/<pack-name>-<draft-name>/` для OpenCode).

## Ссылки между черновиками

Преобразуй `@draft(<draft-name>)`, используя `<pack-name>` из `manifest.yaml`:

| Режим черновика | Antigravity | Codex | Claude Code | OpenCode |
|---|---|---|---|---|
| Явный | `[<pack-name>:<draft-name>](slashCommand;<pack-name>:<draft-name>)` | `$<pack-name>:<draft-name>` | `/<pack-name>:<draft-name>` | `/<pack-name>-<draft-name>` |
| Неявный | `[<pack-name>:<draft-name>](rule;<pack-name>:<draft-name>)` | `$<pack-name>:<draft-name>` | `/<pack-name>:<draft-name>` | `/<pack-name>-<draft-name>` |

## Ошибки компиляции

- черновик не соответствует [формату черновиков](<../Формат черновиков.md>);
- `manifest.version`, имя черновика не уканазы или не соответствуют формату;
- пользовательское условие отсутствует в `manifest.custom_conditions`;
- ссылка `@draft(...)` указывает на отсутствующий или неоднозначный черновик.
