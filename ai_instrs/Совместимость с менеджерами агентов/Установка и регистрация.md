Эта инструкция описывает процесс переноса собранных кастомизаций в систему пользователя и их активации в менеджере агентов.

## Общий принцип установки

Сначала используй стандартные директории, из которых менеджер автоматически обнаруживает кастомизации. Считай размещение файлов в такой директории завершенной установкой и не добавляй отдельную регистрацию. Если автообнаружение недоступно, выполни минимально необходимую регистрацию и, при наличии такой возможности, настрой пакет как установленный по умолчанию. Определяй способ установки только по официальной документации менеджера.

**КРИТИЧЕСКИЕ ПРАВИЛА БЕЗОПАСНОСТИ И ЧИСТОТЫ УСТАНОВКИ:**
1. **Запрет на несанкционированные действия:** ККАТЕГОРИЧЕСКИ ЗАПРЕЩЕНО выполнять любые команды создания, редактирования, копирования или удаления файлов в системных/пользовательских каталогах вне рабочего пространства БЕЗ получения предварительного явного текстового согласия пользователя непосредственно в чате. Сначала опиши действия и запроси разрешение; запускай команды только после подтверждения. Повторяй запрос для каждой новой операции, независимо от прошлых одобрений.
2. **Требование полной очистки:** Перед копированием удали только прежние целевые файлы и директории этого пака. Не затрагивай кастомизации других паков.

## 1. Пути установки

| Менеджер | Путь установки в систему |
| :--- | :--- |
| **Antigravity** | `~/.gemini/config/plugins/impl_instrs/` |
| **Codex** | `~/plugins/impl_instrs/` (WSL Linux) |
| **Claude Code** | Скопируй `integrated_en/claude-code/` целиком в `~/.claude/skills/impl_instrs/`. Сохрани `.claude-plugin/plugin.json` и структуру `skills/*/SKILL.md`; Claude Code загрузит plugin как `impl-instrs@skills-dir`. |
| **OpenCode** | Скопируй содержимое `integrated_en/opencode/skills/` в `~/.config/opencode/skills/`, а `integrated_en/opencode/commands/` — в `~/.config/opencode/commands/`. Сохрани плоские имена `impl-instrs-*`: OpenCode не предоставляет вложенную группу или пространство имен для Agent Skills. |

## 2. Активация плагина Codex (WSL)
Для работы в Codex зарегистрируйте плагин, добавив следующий блок в файл `~/.agents/plugins/marketplace.json`:

```json
{
  "name": "personal",
  "interface": {
    "displayName": "Personal"
  },
  "plugins": [
    {
      "name": "impl-instrs",
      "source": {
        "source": "local",
        "path": "./.codex/plugins/impl_instrs"
      },
      "policy": {
        "installation": "INSTALLED_BY_DEFAULT",
        "authentication": "ON_USE"
      },
      "category": "Productivity"
    }
  ]
}
```
