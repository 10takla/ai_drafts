Эта инструкция описывает процесс переноса собранных кастомизаций в систему пользователя и их активации в менеджере агентов.

## Общий принцип установки

Сначала используй стандартные директории, из которых менеджер автоматически обнаруживает кастомизации. Считай размещение файлов в такой директории завершённой установкой и не добавляй отдельную регистрацию. Если автообнаружение недоступно, выполни минимально необходимую регистрацию и, при наличии такой возможности, настрой пакет как установленный по умолчанию. Определяй способ установки только по официальной документации менеджера.

**КРИТИЧЕСКИЕ ПРАВИЛА БЕЗОПАСНОСТИ И ЧИСТОТЫ УСТАНОВКИ:**
1. **Запрет на несанкционированные действия:** КАТЕГОРИЧЕСКИ ЗАПРЕЩЕНО выполнять любые команды создания, редактирования, копирования или удаления файлов в системных или пользовательских каталогах вне рабочего пространства БЕЗ предварительного явного текстового согласия оператора непосредственно в чате. Сначала опиши действия и запроси разрешение; запускай команды только после подтверждения. Повторяй запрос для каждой новой операции независимо от прошлых одобрений.
2. **Требование полной очистки:** Перед копированием удали только прежние целевые файлы и директории устанавливаемого пака. Не затрагивай кастомизации других паков.

## 1. Пути установки

Получи `<pack-name>` из поля `name` исходного `manifest.yaml`. Используй соответствующую поддиректорию `outputDir` как источник.

| Менеджер | Путь установки в систему |
| :--- | :--- |
| **Antigravity** | `~/.gemini/config/plugins/<pack-name>/` |
| **Codex** | `~/.codex/plugins/<pack-name>/` (на Windows — `%USERPROFILE%\.codex\plugins\<pack-name>\`, на WSL/Linux — `~/.codex/plugins/<pack-name>/`) |
| **Claude Code** | Скопируй `outputDir/claude-code/` целиком в `~/.claude/skills/<pack-name>/`. Сохрани `.claude-plugin/plugin.json` и структуру `skills/*/SKILL.md`; Claude Code загрузит skills-directory plugin. |
| **OpenCode** | Скопируй содержимое `outputDir/opencode/skills/` в `~/.config/opencode/skills/`, а `outputDir/opencode/commands/` — в `~/.config/opencode/commands/`. Сохрани собранные плоские имена `<pack-name>-*`. |

## 2. Активация плагина Codex (Windows и WSL)

Для работы в Codex зарегистрируй плагин, добавив следующий объект пака в `plugins` файла `~/.agents/plugins/marketplace.json` (на Windows — `%USERPROFILE%\.agents\plugins\marketplace.json`, на WSL/Linux — `~/.agents/plugins/marketplace.json`):

```json
{
  "name": "personal",
  "interface": {
    "displayName": "Personal"
  },
  "plugins": [
    {
      "name": "<pack-name>",
      "source": {
        "source": "local",
        "path": "./.codex/plugins/<pack-name>"
      },
      "policy": {
        "installation": "INSTALLED_BY_DEFAULT",
        "authentication": "ON_USE"
      },
      "category": "Productivity"
    }
  ]
}
```
